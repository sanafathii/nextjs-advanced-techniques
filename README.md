# Advanced Next.js Techniques

A practical learning repository for studying and implementing advanced Next.js techniques.

This repository is based on the **Advanced Next.js** course by Classbon and is focused on understanding the concepts, implementing them independently, and experimenting with real-world use cases.

> The goal is not to copy the course code, but to understand the concepts and build them independently.

---

## 🎯 Goals

The main goals of this repository are:

- Improve my understanding of advanced Next.js concepts
- Practice production-oriented frontend techniques
- Understand image loading and optimization
- Build reusable and scalable solutions
- Practice Git and GitHub workflow
- Document what I learn for future reference

## 🌿 Git Workflow

Each major topic is developed in its own feature branch.

Example:

```bash
git checkout -b feature/skeleton-loading
```

After completing the topic:

```bash
git add .
git commit -m "feat: implement skeleton loading"
```

Then the branch will be merged into `main`.

### Branch Naming

```text
feature/<topic-name>
```

Examples:

```text
feature/skeleton-loading
feature/blur-image
feature/image-storage
feature/icon-management
```
